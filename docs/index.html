GOLDATOM

proof-buried digital matter
research home page — September 2, 2026
STATUS: The object layer works in simulation and private Bitcoin Core regtest. The monetary scarcity layer remains experimental. There is no mainnet profile, token sale, presale, ticker, or investment product.

GoldAtom is an attempt to create an independently assayable digital object whose work, birth, Bitcoin history, and current title can be verified rather than trusted.

A version-zero atom combines:

Bit-Gold-style local proof of work
        +
a claim fixed before a future Bitcoin challenge
        +
a mint committed back into Bitcoin
        +
subsequent Bitcoin chainwork burial
        +
one single-use Bitcoin UTXO title

The compact definition: a GoldAtom is a local proof bound to a pre-existing Bitcoin claim, derived from an unknowable future Bitcoin block, committed back into Bitcoin, buried beneath later chainwork, and transferred through a single-use title seal.

What has actually run

  • 31 deterministic, adversarial, RPC, and economic-model tests passed.
  • A fresh isolated Bitcoin Core regtest lifecycle completed: claim → future challenge → local work → mint → burial → verification.
  • An independent Node.js implementation recomputed the portable commitments and obtained the same Atom ID.
  • Tampered work and tampered challenge data were rejected.
  • Removing the challenge block from active history invalidated the atom; restoring the block restored validity.

The current monetary direction: Proof-Cast Tickets

The promising next move is to require proof of work to manufacture a ticket before anybody knows whether an epoch contains a vein or which ticket will win.

prospector performs PoW
        ↓
ticket is published before the draw
        ↓
future claimant-independent Bitcoin history decides whether ore exists
        ↓
the same future history ranks the already-published tickets
        ↓
one winning ticket may settle one open vein into one title

History controls supply. Work controls allocation. Bitcoin controls chronology and title.

More hashing may buy more chances of extracting an existing vein. It must not create more veins. Ten tickets and ten billion tickets can change who wins, but an epoch still produces at most one atom.

Read the Proof-Cast Tickets research note.

What remains unproven

  • A defensible global supply law and production difficulty profile.
  • Resistance to source-miner block withholding, censorship, and fee shocks.
  • A work function and ticket publication system that do not collapse into hidden hardware advantage or unbounded data volume.
  • Mainnet safety, wallet interoperability, privacy, economic adoption, and legal treatment.
  • Independent external cryptographic and Bitcoin protocol review.

The accurate claim is: GoldAtom is a legitimate executable protocol-research project. It is not yet proven digital gold.

Run the object-layer simulation

unzip goldatom-0.0.3-source.zip
cd goldatom-0.0.3
python3 -m unittest discover -s tests -v
python3 -m goldatom simulate

Run the Observatory replay

python3 -m pip install goldatom_observatory-0.1.0-py3-none-any.whl
goldatom-observatory serve

open http://127.0.0.1:8787/

Python 3.11 or newer is required. The packages have no third-party runtime dependencies. Regtest targets are intentionally trivial and prove the state machine, not economic scarcity. Do not use real funds.
